패치 버전 0.1.3 / Windows 설치 도구 0.1.3 / 빌드 20261106.10
Steam/PCVR, Android 휴대폰 설치, 다른 게임 빌드와 기기는 지원하지 않습니다.

필수 환경
Windows 10/11 64비트, Microsoft Edge WebView2 Runtime, .NET Framework 4.8,
정품 게임이 설치된 Quest 3, 개발자 모드와 USB 디버깅, 데이터 전송용 USB 케이블.
Python은 EXE에 포함되어 별도 설치하지 않습니다.
ADB가 없으면 Google 공식 Platform Tools 37.0.0을 약관 동의 후 자동 다운로드합니다.
다운로드 파일 SHA-256을 확인한 뒤 사용하며, 정상 캐시와 동의는 재사용합니다.
최초 ADB 준비와 GitHub 최신 버전 확인에는 인터넷이 필요합니다.
ADB가 준비되어 있고 패치 EXE가 있으면 인터넷 없이 설치·복구할 수 있습니다.

필요 공간
처음 설치할 때 PC에 약 9 GiB, Quest에 4.2 GiB 이상 여유 공간을 권장합니다.
PC 원본 백업 약 3.7 GiB + 생성 결과 약 3.7 GiB + EXE/임시 압축 해제/여유분을 반영했습니다.
Quest의 현재 게임·기존 백업 외에 교체용 파일 약 3.7 GiB가 추가로 필요합니다.
실제 남은 공간을 작업 전에 확인하며, 부족하면 설치하지 않습니다.

설치
1. PAYDAY_Quest_Windows_v0.1.3.exe를 실행합니다.
2. Quest를 USB로 연결하고 헤드셋 안에서 USB 디버깅을 허용합니다.
3. 게임을 완전히 종료합니다. 설치기는 게임을 강제 종료하지 않습니다.
4. 자동으로 기기를 찾으면 '한글패치 설치'를 누릅니다.
5. 원본 검사 → 백업 → 패치 생성·검사 → 전송·검사 → 교체·결과 검증이 끝날 때까지 기다립니다.
   설치 완료 안내가 나온 후 게임을 실행하세요. APK 재설치·앱 삭제·세이브 변경은 하지 않습니다.
여러 실제 기기가 연결되어 있을 때만 대상 선택을 요청합니다.

최신 버전
같은 EXE를 다시 실행하면 GitHub 공개 안정 릴리스의 최신 버전을 확인합니다.
최신 여부를 확인하려고 EXE를 다시 받을 필요는 없습니다. '다시 확인'으로 재시도할 수 있습니다.
시험판·초안·다른 플랫폼 자산은 제외합니다. 최신 설치본이 있으면 다운로드 페이지를 엽니다.
설치된 버전은 연결된 기기의 실제 파일과 설치 기록으로 확인합니다.
네트워크 실패는 '버전 확인 실패'로 표시하며 '최신' 또는 '미설치'로 처리하지 않습니다.
공개 릴리스가 없는 배포 준비 단계에서는 공개 배포본 없음 또는 버전 확인 실패가 정상입니다.

제거·복구
게임을 종료하고 같은 EXE의 '제거 · 원본 복구'를 누릅니다.
검증된 원본을 복원하고 한글패치 설치 상태를 갱신합니다. 세이브 진행 상황은 유지됩니다.
원본 백업은 나중의 복구를 위해 보존합니다. EXE를 이동하거나 다시 받아도 사용할 수 있습니다.
기기 원본 백업과 PC 백업은 모두 해시를 확인하며, 알 수 없는 파일·게임 업데이트본은 덮어쓰지 않습니다.

정확한 파일 해시로 식별하여 검증된 원본에서 업데이트합니다.
0.1.3-test.3은 이번 배포판과 게임 파일이 동일하며 설치 기록을 갱신할 수 있습니다.

기록이 없더라도 실제 패치 파일·기기 원본을 검증한 뒤에만 새 기록을 만들며 백업을 덮어쓰지 않습니다.

중단된 작업
USB를 다시 연결하고 게임을 종료한 후 설치기를 실행합니다.
'중단된 작업 복구'가 표시되면 버튼을 눌러 기록과 실제 파일을 검증합니다.
교체가 끝났으면 완료 기록을 복원하고, 교체 중 원래 파일이 이동된 상태면 검증 후 직전 상태를 복원합니다.
판단할 수 없는 파일은 그대로 보존하고 오류를 표시합니다. 백업·transaction.json·잠금 파일을 임의로 지우지 마세요.
설치기 실행 중에는 닫기가 제한되지만 PC 종료·전원 단절 같은 중단은 다음 실행에서 확인합니다.

번역 범위와 알려진 제한
메뉴·장비·설정·브리핑·임무·상점·도전 과제, 도입 영상 자막, 지도 6종,
튜토리얼 포스터, 구역 알림, 벽·게시판 글꼴, DLC 원화 가격 표시 보정이 포함됩니다.
드릴 디스플레이는 그대로 유지했습니다. 이미지·영상·온라인 콘텐츠 등 일부 영어가 남을 수 있습니다.
임무 알림은 사용자 확인 완료, 가방 획득 알림은 실제 게임 표시 확인을 미뤄 두었습니다.
모든 미션·협동 상황·장시간 플레이를 검증한 것은 아닙니다.
게임 업데이트 후에는 호환성을 다시 확인해야 합니다. 업데이트 전 원본 복구를 권장합니다.
