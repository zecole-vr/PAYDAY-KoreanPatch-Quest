# v0.1.5 검증 기록

게임 버전 1.1(빌드 131336), 설치 도구 빌드 20261119.1을 대상으로 확인했습니다.
이전 버전 기록은 [v0.1.4 검증 기록](VALIDATION-v0.1.4.md)에 보관했습니다.

## 변경점 및 번역
새 원본 APK·OBB를 실제 Quest 3에서 가져와 기기 체크섬과 대조했습니다.
변경된 PAK 7개와 실행 스크립트 75개(신규 1개)를 빌드 131115 원본과 비교했습니다.
문자열 표의 새 문구 55개와 원문이 바뀐 문구 39개, 화면 부품 문구 15개, 실행 중 알림 10개를 번역했습니다.
리소스는 3,471개이며, 기존 실행 문구 196개를 새 캐시에 대응시켰습니다.
이전에 번역한 실행 문구 15개는 새 빌드에서 화면 부품으로 옮겨져, 해당 위치에서 다시 번역했습니다.
기존 수정 자산 51개 중 원본이 바뀐 것은 작전 문자열 표(ST_Heist) 하나이며, 새 원본 기준으로 다시 만들었습니다.
신규 번역은 별도 검토(Codex 교차 검토)를 거쳐 9개 항목을 고쳤습니다.

## 완료한 확인
- 13개 네이티브 함수·형식 참조를 변하지 않은 모듈의 4,825개 사용 위치로 대조했습니다.
- 수정한 스크립트 캐시를 독립 검증해, 대상 외 모듈 1,101개와 바인딩·속성 테이블이 새 원본과 일치함을 확인했습니다.
- 알림 변환 234개 사례, 설치 엔진 시험 16개, 런처 시험 7개를 통과했습니다.
- DLC 원화 가격 처리 경로(426개 명령)가 빌드 131115와 같음을 확인했습니다.
- 생성한 OBB 크기는 원본과 같은 3,967,243,545바이트이며, 두 PAK 분석기와 전체 ZIP CRC로 확인했습니다.
- PC에서 원본과 배포 데이터로 같은 OBB를 다시 만들어 해시가 일치함을 확인했습니다.
- 실제 Quest 3에 배포 설치 엔진으로 설치하고, 기기 패치본·기기 원본 백업·PC 원본 백업의 해시를 검증했습니다.
- 설치 후 게임이 정상 실행되었고, 사용자가 게임 화면의 한글 표시를 확인했습니다.
- 실제 배포 EXE 안의 bundle/manifest.json, bundle/data/recipe.json, bundle/data/payload.bin 경로와 해시,
  0.1.4와 같은 매니페스트 키 구성, WebView 화면·도움말·설치 v0.1.5 표시를 확인했습니다.

## 남은 확인 범위
이번 빌드에서 원본 복구·재설치 실기 반복 시험은 하지 않았습니다(엔진 시험과 이전 빌드 실기 시험으로 대신함).
협동 플레이의 파티 알림, 모든 미션과 장시간 플레이,
별도의 개발 환경 없는 새 Windows PC, 실제 케이블 분리·전원 차단은 추가 확인이 필요합니다.
