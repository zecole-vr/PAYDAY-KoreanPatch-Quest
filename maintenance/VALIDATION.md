# v0.1.4 검증 기록

게임 빌드 131115, 설치 도구 빌드 20261107.11을 대상으로 확인했습니다.

## 변경점 및 번역
새 원본 APK·OBB를 실제 Quest 3에서 가져와 체크섬을 확인했습니다.
변경된 PAK 7개와 실행 스크립트를 기존 원본과 비교했습니다.
작전 포기·작전 재시작 버튼 2개, 파티장의 작전 포기·재시작 알림 2개를 번역했습니다.
리소스는 3,403개이며, 기존 실행 문구 212개를 새 캐시에 대응시켰습니다.
기존 수정 자산 51개의 원본 내용이 새 게임에서도 동일함을 확인했습니다.

## 완료한 확인
- 13개 네이티브 함수·형식 참조를 변하지 않은 모듈의 5,486개 사용 위치로 대조했습니다.
- 새 캐시의 전체 문자열 4,932개, 수정한 UI 메서드 31개를 다시 분석했습니다.
  대상 외 모듈 1,100개와 바인딩·속성 테이블이 새 원본과 일치합니다.
- 알림 변환 234개 사례, 설치 엔진 시험 16개, 런처 시험 7개를 통과했습니다.
- 생성한 OBB 크기는 원본과 같은 3,968,297,513바이트이며, 두 PAK 분석기와 전체 ZIP CRC로 확인했습니다.
- 실제 Quest 3에서 설치, 원본 복구, 재설치, 같은 버전 재설치 확인을 실행했습니다.
  각 작업은 배포 설치 엔진을 직접 호출했고 최종 파일·원본 백업의 해시를 검증했습니다.
- 130623과 131115의 PC 원본 백업을 각각 검증했습니다.
- 실제 배포 EXE의 내장 파일·런타임·WebView 화면·도움말·설치 v0.1.4 표시를 확인했습니다.
- 사용자가 DLC 가격과 새 메뉴 버튼에 대해 ‘둘다 정상’이라고 확인했습니다.

## 남은 확인 범위
새 파티 알림의 협동 상황별 실제 화면, 가방 알림, 모든 미션과 장시간 플레이,
별도의 개발 환경 없는 새 Windows PC, 실제 케이블 분리·전원 차단은 추가 확인이 필요합니다.
기본 UI는 v0.1.3에서 확인한 공통 화면을 재사용했습니다.
공개 후 로그인 없이 EXE와 체크섬 파일을 내려받아 일치를 확인했습니다.
다운로드한 EXE를 실행해 설치 버전 및 GitHub 최신 버전 v0.1.4 표시를 확인했습니다.
기존 v0.1.3 EXE에서도 v0.1.4 업데이트가 있음을 감지했습니다.
첫 접속에서 인증서 확인 오류와 HTTP 504가 발생했고, 재시도 후 정상 응답과 표시를 확인했습니다.
상세 기록은 [공개 배포 검증](public-verification.json)에 있습니다.
