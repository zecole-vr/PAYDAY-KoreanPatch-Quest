## v0.1.5 업데이트

- 새로 생긴 문구 55개와 원문이 바뀐 문구 39개를 번역했습니다.
- 화면 부품 문구 15개, 파티·친구 알림 10개를 번역했습니다.
- 은행 강도 팩과 새 DLC 무기·방패, 게이지의 상점 **'해제'** 방식 변경을 반영했습니다.
- 기존 임무·가방 알림을 새 실행 스크립트 구조에 맞춰 다시 적용했습니다.

> 게임을 빌드 131336으로 업데이트한 뒤 설치해 주세요. 원본 백업과 설치 기록은 게임 빌드별 폴더에 보관합니다.

## 설치

**[ZECOLE_Launcher.exe 받기](https://github.com/zecole-vr/zecole-launcher/releases/latest/download/ZECOLE_Launcher.exe)** · 설치 없이 바로 실행 · 설치·업데이트·원본 복구를 모두 런처에서 합니다.

1. Quest 3의 개발자 모드를 켜고 데이터 전송용 USB 케이블로 PC와 연결합니다. 헤드셋에서 USB 디버깅을 허용합니다.
2. 게임을 완전히 종료합니다.
3. 런처를 실행하고 왼쪽 목록에서 **PAYDAY: Aces High**를 고릅니다.
4. **한글패치 설치**를 누른 뒤 완료 안내가 나올 때까지 기다립니다.

### 알아 둘 점

- 런처는 게임·패치 파일 확인 → 원본 백업 → 패치 생성 → 전송 → 결과 검증을 순서대로 처리합니다.
- APK 재설치, 앱 삭제, 세이브 변경은 하지 않습니다.
- ADB가 없으면 약관 동의 후 Google 공식 Platform Tools를 받아 체크섬을 검증합니다.
- ADB 준비와 최신 버전 확인에는 인터넷이 필요합니다.
- 새 한글패치 버전이 나오면 런처가 **업데이트 있음**으로 알려 주며, 같은 화면에서 설치하면 됩니다.

## 제거와 복구

1. 게임을 종료합니다.
2. 런처의 PAYDAY 화면에서 **원본 복구**를 누릅니다.

- 원본 백업과 세이브 진행 상황은 유지됩니다.
- 예전 설치기 EXE로 설치했어도 런처가 사용자 앱 데이터에 보관한 백업·설치 기록을 이어서 사용합니다.
- USB 분리나 PC 종료로 중단되면 다시 연결하고 런처에서 다시 실행해 주세요.
- 판단할 수 없는 파일은 자동으로 덮어쓰지 않습니다.
