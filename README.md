# PAYDAY: Aces High — Quest 한국어 패치

제작자 · **제콜 (ZECOLE)** · [YouTube](https://www.youtube.com/@zecole)

**Meta Quest 단독판 / Quest 3 / 게임 빌드 131115**용 비공식 한국어 패치입니다.
패치 **v0.1.4**, Windows 설치 도구 **v0.1.4 (20261107.11)**.

## v0.1.4 업데이트

게임 빌드 **131115**에 대응했습니다. 새 일시정지 메뉴의 **작전 포기·작전 재시작**과
**파티장이 작전을 포기하거나 재시작했다는 알림**을 번역했습니다.
기존 임무·가방 알림은 새 실행 스크립트 구조에 맞춰 적용했습니다.

게임을 빌드 131115로 업데이트한 뒤 v0.1.4를 설치해 주세요.
게임 빌드 130623용 설치기는 [v0.1.3 릴리스](https://github.com/zecole-vr/PAYDAY-KoreanPatch-Quest/releases/tag/v0.1.3)에서 받을 수 있습니다.
원본 백업과 설치 기록은 게임 빌드별 폴더에 보관합니다.

## 다운로드와 설치

[Windows 설치 EXE 다운로드 · 70.5 MB](https://github.com/zecole-vr/PAYDAY-KoreanPatch-Quest/releases/download/v0.1.4/PAYDAY_Quest_Windows_v0.1.4.exe) · [v0.1.4 릴리스 및 체크섬](https://github.com/zecole-vr/PAYDAY-KoreanPatch-Quest/releases/tag/v0.1.4)

1. EXE를 실행하고 Quest 3를 USB로 연결합니다.
2. 헤드셋에서 USB 디버깅을 허용하고 게임을 완전히 종료합니다.
3. **한글패치 설치**를 누른 뒤 완료 안내가 나올 때까지 기다립니다.

설치기는 게임·패치 파일 확인, 원본 백업, 패치 생성, 전송, 결과 검증을 순서대로 처리합니다.
APK 재설치, 앱 삭제, 세이브 변경은 하지 않습니다.

## 최신 버전 확인

같은 EXE를 다시 실행하면 **GitHub 최신 한글패치**를 확인합니다.
최신 버전 유무를 확인하려고 EXE를 새로 받을 필요는 없습니다.
새 배포본이 있으면 다운로드 페이지를 열 수 있으며, 확인 실패 시 **다시 확인**을 누르세요.
시험판·릴리스 초안·다른 플랫폼용 파일은 제외합니다.

## 제거와 복구

게임을 종료한 뒤 **제거 · 원본 복구**를 누릅니다. 원본 백업과 세이브 진행 상황은 유지됩니다.
EXE를 옮기거나 다시 받아도 사용자 앱 데이터에 보관한 백업·설치 기록을 이어서 사용합니다.
USB 분리나 PC 종료로 중단되면 다음 실행에서 **중단된 작업 복구**를 확인해 주세요.
판단할 수 없는 파일은 자동으로 덮어쓰지 않습니다.

## 필수 환경

- Windows 10/11 64비트, Microsoft Edge WebView2 Runtime, .NET Framework 4.8
- 정품 게임이 설치된 Quest 3, 개발자 모드·USB 디버깅, 데이터 전송용 USB 케이블
- 첫 설치 시 PC 약 9 GiB / Quest 4.2 GiB 이상 여유 공간
- 최초 ADB 준비와 최신 버전 확인을 위한 인터넷 연결

Python은 EXE에 포함됩니다. ADB가 없으면 약관 동의 후 Google 공식 Platform Tools 37.0.0을
다운로드하고 체크섬을 검증합니다. 이미 준비된 연결 도구·동의는 재사용합니다.

## 포함 범위와 제한

메뉴·설정·장비·임무·브리핑·상점·도전 과제, 도입 영상 자막, 지도 6종과 튜토리얼 포스터,
구역 알림, 벽·게시판 한글 글꼴, DLC 원화 가격 표시 보정을 포함합니다.
드릴 디스플레이는 유지했으며, 일부 이미지·온라인 콘텐츠 등에 영어가 남을 수 있습니다.
가방 획득 알림은 수정되어 있으나 실제 게임 화면 확인은 아직 하지 않았습니다.
모든 미션·협동 조합·장시간 플레이를 검증한 것은 아닙니다.
다른 게임 빌드, Steam/PCVR, Android 휴대폰 설치 및 Quest 3 이외 기기는 지원하지 않습니다.
게임 업데이트 후 호환성은 별도로 확인해야 합니다. 업데이트 전에 원본 복구를 권장합니다.
